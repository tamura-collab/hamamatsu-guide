温暖な気候と豊かな自然に恵まれた浜松市ですが、遠州灘に面した沿岸部、浜名湖、天竜川、そして北部の山間地まで、市域が広いぶん、地域によって備えるべき災害は異なります。

この記事では、浜松に暮らす人、これから引っ越してくる人に向けて、南海トラフ地震と津波への備え、ハザードマップの見方、防災情報の受け取り方、家庭でできる備えまでをまとめました。

## 浜松で想定される主な災害

| 災害 | 主に注意が必要な地域 | ポイント |
| :--- | :--- | :--- |
| 地震（南海トラフ地震） | 市内全域 | 強い揺れによる建物の倒壊、家具の転倒 |
| 津波 | 遠州灘沿岸部、浜名湖周辺 | 沿岸から離れる・高い場所へ逃げる |
| 洪水・浸水 | 天竜川・馬込川などの河川沿い、低い土地 | 大雨・台風のときの早めの避難 |
| 土砂災害 | 天竜区など北部の山間地 | 大雨のときの崖崩れ・土石流 |

※自宅や職場がどの災害に注意すべき場所かは、浜松市のハザードマップで確認してください。

## 南海トラフ地震と津波への備え

### 浜松で想定されている津波

浜松市は、南海トラフ地震で大きな被害が想定されている地域のひとつです。2025年3月に国が公表した新しい被害想定では、浜松市の最大津波高は**17m**とされ、前回（2012年）の想定の16mから引き上げられました。

これは「最大クラス」の地震を前提にした数字で、すべての沿岸に同じ高さの津波が来るという意味ではありません。地域ごとの浸水の深さは、浜松市の津波浸水深マップで確認できます。

浜松市の津波避難計画では、遠州灘の沿岸部について、津波が砂丘を越えて内陸に浸水するまで約20分とし、**揺れがおさまったら5分程度を目安に避難を始める**ことを求めています。浜名湖の周辺や河川の河口付近では、より早く浸水が始まる場所もあるため、「揺れたらすぐ逃げる」が基本です。

### 浜松の沿岸を守る「防潮堤」

浜松市の沿岸では、天竜川から浜名湖の今切口（いまぎれぐち）までの約17.5kmにわたって、高さ（標高）13mの防潮堤が整備され、**2020年（令和2年）3月に本体が完成**しました。地元企業の一条工務店グループが静岡県に300億円を寄付し、県が整備を進めたことで知られています。

ただし、防潮堤があるからといって安全というわけではありません。想定を超える津波が来る可能性もあり、防潮堤の外側にあたる浜名湖周辺や河口部などでは、引き続き早めの避難が欠かせません。

### 「南海トラフ地震臨時情報」が出たら

南海トラフ沿いで大きな地震が起きたときなどには、気象庁から**「南海トラフ地震臨時情報」**が発表されることがあります。2024年8月には初めて「巨大地震注意」が発表されました。

臨時情報が出たときは、すぐに避難が必要というわけではありませんが、避難場所や避難経路を確認し、家具の固定や備蓄を見直して、いつでも逃げられる準備をしておきましょう。

## ハザードマップで自宅のリスクを確認する

浜松市は、地震・津波・洪水・土砂災害などのリスクをまとめた**浜松市防災マップ**や**津波浸水深マップ**を公開しています。パソコンやスマートフォンで見られるほか、紙の洪水ハザードマップは市役所や区役所で配布されています。

確認しておきたいのは次の3点です。

1. **自宅・職場・学校が、浸水や土砂災害のおそれのある区域に入っているか**
2. **近くの避難場所・津波避難ビルなどの場所**
3. **避難場所までのルート**（川や低い土地を通らずに行けるか）

家族で一度、実際に避難場所まで歩いてみると、時間の感覚や道の危険箇所がつかめます。

### 家を探すときにも確認を

移住や転勤で浜松に住まいを探すときは、物件を決める前にハザードマップを確認しておくのがおすすめです。沿岸部や河川沿いでも、避難できる高い建物や高台が近くにあるかどうかで安心感は変わります。不動産会社には、取引の際に水害ハザードマップでの物件の位置を説明することが義務づけられているので、気になることは遠慮なく聞いてみましょう。エリアの特徴は[新3区の住みやすさガイド](/articles/hamamatsu-living-areas)も参考にしてください。

## 防災情報の受け取り方

いざというときに情報を確実に受け取れるよう、複数の手段を用意しておきましょう。

| 手段 | 内容 |
| :--- | :--- |
| 浜松市防災ホッとメール | 緊急情報や地域の防災情報、気象情報をメールで受け取れる市のサービス。登録は無料（通信料は自己負担） |
| 同報無線（防災行政無線） | 屋外のスピーカーで避難の呼びかけなどを放送 |
| 緊急速報メール（エリアメール） | 携帯電話会社を通じてスマートフォンに届く |
| テレビ・ラジオ | 停電に備えて電池式・手回し式のラジオがあると安心 |

防災ホッとメールは、市のホームページから空メールを送るだけで登録できます。引っ越してきたら、早めに登録しておきましょう。

## 台風・大雨への備え

2022年9月の台風15号では、浜松市でも記録的短時間大雨情報が発表され、市は災害救助法の適用を受けました。天竜区ではボランティアセンターが設置されるなど、大雨による被害も身近な災害です。

- 台風が近づく前に、ハザードマップで自宅周辺の浸水・土砂災害のリスクを確認する
- 雨が強くなる前、明るいうちに避難を済ませる
- 浸水のおそれがある地域では、車を高い場所へ移動しておく

## 家庭でできる備え

### 住まいの耐震化

古い木造住宅に住んでいる人は、耐震診断を受けておくと安心です。浜松市では、無料で専門家が耐震診断を行う**「わが家の専門家診断」**と、補強工事の費用を補助する**木造住宅耐震補強助成事業**を実施しています（補助額や受付期間は年度によって異なるため、市の最新情報を確認してください）。

### 家具の固定

地震によるけがの多くは、家具の転倒や落下によるものです。寝室や子ども部屋には背の高い家具を置かない、置く場合は金具で固定するなど、できることから始めましょう。

### 備蓄

国は、食料や飲料水を**最低3日分、できれば1週間分**備えておくことをすすめています。

- 飲料水（1人1日3リットルが目安）
- 日ごろ食べている食品を多めに買い置きし、使った分を買い足す「ローリングストック」
- 携帯トイレ、懐中電灯、モバイルバッテリー、常備薬

車社会の浜松では、車にも水や簡易トイレ、毛布などを積んでおくと、外出先で被災したときに役立ちます。

## 地域とのつながりも防災のひとつ

浜松市では、自治会を単位とした**自主防災隊**が組織され、地域ごとに防災訓練が行われています。引っ越してきたら、自治会の防災訓練に一度参加してみると、近所の人と顔見知りになれるうえ、地域の避難場所や危険な場所も自然に覚えられます。

## まとめ：「知って、備えて、すぐ逃げる」

- **知る**：ハザードマップで自宅・職場のリスクと避難場所を確認する
- **備える**：耐震化・家具の固定・備蓄、防災ホッとメールの登録
- **すぐ逃げる**：沿岸部では揺れがおさまったらすぐに高い場所へ

浜松は、日照時間が長く暮らしやすい街です。正しく備えておけば、その魅力を安心して楽しめます。
